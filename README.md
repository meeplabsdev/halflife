# Starbie
|![front of the board](./starbie/front.png)|![back of the board](./starbie/back.png)|
|---|---|

Starbie is a tiny (4x4cm) device with two buttons, a gyro+accelerometer and temperature+humidity sensor. Alongside the controls, you can interact with it by physically moving the board.

# What it is
This project was created following the week 1 beginner [tutorial](https://github.com/SharKingStudios/Starbie) for [halflife](https://halflife.hackclub.com/)!

# Software
[`firmware/`](starbie/firmware/) contains one Arduino IDE sketch for the XIAO ESP32-C3 that shows the state of the gyro+accelerometer, temperature, humidity, and counts the number of times each button has been pressed.
